# 股价异常波动原因分析技能

当股票出现异动（价格暴涨暴跌、成交量异常放大、技术指标极端值等）时，你需要像专业分析师一样，快速定位异常原因并给出可操作的指导建议。


## 📋 分析流程 (SOP)

### 阶段1：数据收集（5步必做）

1. **获取异常检测结果**（起点）
   - 调用 `detect_anomalies` 快速确认异常类型（价格异动/成交量异常/RSI超买超卖等）
   - 获取异动强度评分

2. **获取详细行情与K线**
   - 调用 `get_stock_quote` 获取实时行情（价格、涨跌幅、成交量、换手率、振幅）
   - 调用 `get_kline` 获取近20日K线数据（确认趋势连续性、关键支撑/压力位）

3. **技术指标深度计算**
   - 调用 `calculate_indicators` 获取完整指标（MA5/10/20/60，RSI，MACD，BOLL，KDJ）
   - 重点关注：RSI是否>80或<20，MACD是否金叉/死叉，BOLL带宽是否急剧收窄或突破，成交量是否突破MA_VOL的1.5倍或2倍

4. **新闻与消息面扫描**
   - 调用 `get_stock_news` 获取近3日相关新闻
   - 对新闻进行情绪分类（正面/负面/中性），标记重要程度（公告/媒体报道/传闻）

5. **市场环境快照**
   - 调用 `get_market_sentiment` 获取大盘情绪（涨跌家数比、涨跌停数量、北向资金流向）
   - 调用 `get_hot_stocks` 获取同板块或同概念热门股票（按成交额或涨跌幅排序）

### 阶段2：归因分析（四维度排查，按优先级顺序）

#### 🔴 维度1：公司基本面突发事件
**数据来源**：`get_stock_news` 筛选“公告”类型新闻  
**判断标准**：
- 业绩预告（预增/预减/亏损）
- 重大合同/中标（金额占营收比例>5%）
- 股权变动（增减持、股权转让、回购）
- 监管处罚、立案调查
- 分红送转预案

**分析要点**：
- 新闻发布与异动的时间差（若异动先于公告，可能存在内幕或预期炒作）
- 事件影响是一次性还是持续性（如一次性资产出售 vs 主营业务改善）
- 同类历史事件后股价表现（可快速检索记忆库）

#### 🟡 维度2：技术面突破/破位
**数据来源**：`calculate_indicators` + `get_kline`  
**判断标准**：
- 价格突破关键位：前期高点/低点、整数关口、MA60/MA120、BOLL上轨/下轨
- 成交量配合：放量突破要求当日成交量 > 5日均量×1.5；无量突破需警惕假突破
- 技术形态：放量长阳/长阴、缺口、十字星、早晨之星/黄昏之星、断头铡刀

**分析要点**：
- 突破后是否出现回踩确认（次日或次三日收盘站稳突破位上方）
- 多个技术指标是否共振（如RSI>70+MACD金叉+放量突破）
- 极端值信号：RSI>85为严重超买，RSI<15为严重超卖；BOLL带宽<0.1预示变盘

#### 🟢 维度3：板块/概念联动
**数据来源**：`get_hot_stocks` 按涨跌幅排序，提取同行业或同概念个股表现  
**判断标准**：
- 同板块涨跌停家数是否≥3家
- 板块指数涨幅是否跑赢大盘1.5倍以上
- 是否有龙头股率先异动（板块内第一个涨停或涨幅最大）

**分析要点**：
- 驱动因素：政策利好（如行业规划发布）、事件催化（如产品涨价）、资金轮动
- 板块持续性：观察板块成交量是否持续放大，龙头股是否连板
- 个股在板块中的地位：龙头跟风弹性大，跟风股持续性差，边缘股一日游概率高

#### 🔵 维度4：大盘情绪影响
**数据来源**：`get_market_sentiment`  
**判断标准**：
- 大盘涨跌幅（上证/创业板）：个股与大盘同向且幅度接近 → 系统性影响
- 涨跌家数比：若全市场上涨家数>3000家，为普涨情绪；<1000家为普跌
- 涨停/跌停数量：>100家涨停为强情绪，>50家跌停为恐慌

**分析要点**：
- 计算个股与大盘的Beta相关性（粗略：个股涨跌幅/大盘涨跌幅，>1.2为高弹性）
- 如果是系统性风险/机会，优先判断大盘趋势，个股操作服从大势
- 个股逆势独立行情往往具有更强的内在驱动力

### 阶段3：综合研判与置信度评分

将四维度分析结果整合，给出结论：

```
异常类型：【单一因素主导 / 多因素共振 / 非理性噪音】
持续性判断：【一日游（<2天） / 短期趋势（3-8天） / 中期反转（2-4周）】
置信度评分：总分10分，从以下维度打分
- 消息面可靠性（公告确认+2，传闻+0，无消息0）
- 技术面健康度（放量+2，缩量+0，背离-1）
- 板块共振强度（强+2，中+1，弱0）
- 大盘配合度（顺大势+1，逆势0，冲突-1）
置信度等级：【高(≥8) / 中(5-7) / 低(≤4)】
```

## ⚠️ 特别注意事项（补充）

1. **区分真假突破（关键技能）**
   - 真突破四要素：放量（>1.5倍均量）、价格收盘站稳、指标共振（MACD金叉等）、次日不回撤突破位
   - 假突破特征：缩量、长上影线、收盘价在突破位附近、次日低开低走

2. **警惕“一日游”行情**
   - 无实质性公告、纯技术反弹、板块跟风且龙头炸板 → 标记为“持续性存疑”
   - 成交量单日异常放大次日急剧萎缩 → 大概率一日游

3. **量化信号与情绪背离时的处理**
   - 技术超买 + 消息面极度利好：趋势优先，但分批止盈
   - 技术超卖 + 基本面持续恶化：不要抄底，等待基本面反转信号
   - 技术超买 + 无消息面：大概率回调，可减仓

4. **仓位管理参考**
   - 高置信度（≥6分）：仓位可至5-10%（短线）或20%（中线）
   - 中置信度（4-5分）：持仓观望或轻仓1-3%
   - 低置信度（≤3分）：减仓至0或离场观望

5. **工具使用最佳实践**
   - 始终先用 `detect_anomalies` 快速扫描，避免手动计算浪费时间
   - 分析完成后，对于需要跟踪的异动股，调用 `add_to_watchlist` 并备注异动原因
   - 若用户要求持续监控，可设置提醒：“我会在明日开盘前再次分析该股”
